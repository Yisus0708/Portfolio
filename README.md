# Portfolio — Jesus Cantillo

Sitio estático (HTML/CSS/JS, sin build) con tema oscuro, azul metálico + negro y una red de partículas animada de fondo.

## Estructura

```
index.html
css/style.css
js/main.js
```

## Uso local

Abre `index.html` directamente en el navegador, o sirve la carpeta con cualquier servidor estático:

```bash
npx serve .
```

## Deploy

Listo para GitHub Pages: activa Pages en la rama `main` (carpeta raíz) en la configuración del repositorio.
