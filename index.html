Etapa 01: Gateway de Entrada & Enrutamiento

FastAPI Asíncrono con Pydantic y Rate Limiting

Cada solicitud entrante se valida mediante esquemas estrictos de Pydantic v2 para garantizar tipos correctos antes de tocar la lógica de negocio. Se aplican políticas de rate limiting por IP/token y manejo centralizado de excepciones con respuestas HTTP semánticas estándar RFC 7807.
